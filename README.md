# 猫咪沙雕短视频生成器 V1

当前版本：`v0.1.0-mvp`（最小可用版本）

这是一个 Windows 本地工具，使用固定参考音频通过 GPT-SoVITS 生成配音，再由 FFmpeg 自动循环或裁剪猫咪视频并合成 MP4。成片时长始终跟随配音时长；配音超过基础视频时自动循环，配音较短时直接裁剪画面。

## 使用方法

1. 双击 `启动.bat`。
2. 选择一个本地视频。
3. 输入文案。
4. 点击“试听配音”或“生成视频”。
5. 在 `output` 文件夹查看结果。

首次生成需要加载本地 GPT-SoVITS 模型，通常需要约 30 秒。程序关闭时会停止由本程序启动的模型服务并释放显存。

## 当前固定配置

- 参考音频：`音频.wav`
- 参考文本：`参考文本.txt`
- TTS：GPT-SoVITS v2Pro，CUDA FP16
- 视频输出：H.264、AAC、yuv420p
- 字幕：已知文案与最终 WAV 做中文 CTC 强制对齐，生成 ASS 后烧录
- 字幕参数：可在 `config.json` 独立调整字数、停顿阈值、最短/最长显示时间
- 输出目录：`output/`

当前音色清晰度仍需后续调整，不影响视频处理和 GUI 功能验证。
