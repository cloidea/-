# 猫咪沙雕短视频生成器 V1

当前版本：`v0.6.1`（制作页快捷生成并上传；真实平台话题仍待复测）

这是一个 Windows 本地工具，使用固定参考音频通过 GPT-SoVITS 生成配音，再由 FFmpeg 裁剪或循环猫咪视频并合成 MP4。成片时长始终跟随最终配音的真实时长；配音超过模板长度时会先询问用户，确认后才使用现有循环功能。

## 使用方法

1. 双击 `启动.bat`。
2. 从缩略图中选择一个视频模板，也可以选择其他本地视频。
3. 输入文案。
4. 在“制作视频”页点击“试听”或底部固定的“仅生成视频”；需要接着上传则点击“生成并上传”。
5. 在 `output` 文件夹查看结果。

失败后使用相同文案再次点击生成，程序会复用有效配音和已完成字幕，从尚未完成的步骤继续。若音色不满意、配音漏字或出现内容匹配错误，展开“更多选项”，先点“下次重新配音”，再生成。同步字幕开关也在这里。

字幕开启时先检查文案。日期（如2026-09-17）、小数、百分比与整数在配音和对齐中使用相同读法，字幕保留原写法。模型不支持的英文、符号或无法确定读音的字会在配音前提示改写，不能保证任意人名、多音字或外语自动正确。

展开“管理模板”，点击“刷新模板”即可重新加载新增或替换的视频，也可以打开模板文件夹或选择本地视频。损坏模板会提示并跳过；最多显示5个有效模板，超出时提示。

生成文件统一命名为 `胖猫成片_年月日_时分秒_标题.mp4`，例如 `胖猫成片_20260917_195430_猫咪冷知识.mp4`。填写了发布标题时优先使用标题；没有填写时自动截取文案开头。界面状态栏会直接显示“本次生成文件”。

如果需要制作后立即上传，在制作页点击“生成并上传”，弹窗填写标题、标签并勾选抖音或小红书（可同时选择），确认后自动生成并上传，无需再次选择成片。也可以在生成结果卡片点击“去发布”。程序在专用 Edge 窗口上传视频、填写标题与正文、尝试选择匹配的话题，最后由你检查封面和内容并点击发布。

如果视频已经制作完成，进入“发布视频”页，点击“选择 / 更换视频”，填写标题和标签、选择平台，再点击“上传并填写”。切换页面不会清空当前输入。

上传直接读取原视频，不再新建 `output/publish` 发布包，不自动删除旧发布包。失败后点“重试失败平台”，仅处理尚未成功的平台；当前发布页仍存在时复用已上传视频。

首次在专用 Edge 窗口登录账号并进入视频上传页面，再点击软件中的“继续上传”。后续登录状态由浏览器保存在本机 `browser_profiles/` 下，不纳入 Git。普通浏览器的登录状态不会自动迁移。遇到验证码请自己处理后继续；“停止上传”停止后续自动操作，已经上传的文件仍保留在网页。

如果话题候选未找到，软件会列出未匹配标签，请在网页手动选择；不会把普通 `#文字` 当作已选择话题。完成后保留发布窗口供检查，程序不会点击最终发布。请完成网页操作后再关闭软件。

自动上传模块已经通过离线流程测试；当前机器的网页检查连接超时，尚未完成真实账号的上传与话题候选联调，首次使用可能需要针对实际页面调整。

依赖为项目环境中的 Playwright（复用已安装的 Edge，无需下载浏览器）。安装依赖：`.venv\Scripts\python.exe -m pip install -r requirements.txt`。实现参考：[Playwright 文件上传](https://playwright.dev/python/docs/input#upload-files)。

界面会根据固定胖猫音色的历史语速显示预计配音时长。该数字只用于提醒；生成后程序会重新读取最终 WAV 的真实时长，并以此决定裁剪或提示循环。

首次生成需要加载本地 GPT-SoVITS 模型，通常需要约 30 秒。程序关闭时会停止由本程序启动的模型服务并释放显存。

## 当前固定配置

- 参考音频：`音频.wav`
- 参考文本：`参考文本.txt`
- TTS：GPT-SoVITS v2Pro，CUDA FP16
- 视频输出：H.264、AAC、yuv420p
- 字幕：已知文案与最终 WAV 做中文 CTC 强制对齐，生成 ASS 后烧录
- 字幕参数：可在 `config.json` 独立调整字数、停顿阈值、最短/最长显示时间
- 输出目录：`output/`
- 视频模板目录：`assets/videos/`（自动读取前 5 个支持的视频文件）
- 半自动发布：抖音、小红书网页版（不保存账号密码，不自动点击最终发布）

配音、字幕对齐和视频合成链路沿用现有模块；自动上传模块独立放在 `publish/browser_uploader.py`。
