# 猫咪沙雕短视频生成器 V1

当前版本：`v0.3.0`

这是一个 Windows 本地工具，使用固定参考音频通过 GPT-SoVITS 生成配音，再由 FFmpeg 裁剪或循环猫咪视频并合成 MP4。成片时长始终跟随最终配音的真实时长；配音超过模板长度时会先询问用户，确认后才使用现有循环功能。

## 使用方法

1. 双击 `启动.bat`。
2. 从缩略图中选择一个视频模板，也可以选择其他本地视频。
3. 输入文案。
4. 点击“试听配音”或“生成视频”。
5. 在 `output` 文件夹查看结果。

如果需要发布，可以同时填写发布标题和标签，选择抖音或小红书，然后点击“生成并准备发布”。程序会创建发布包、复制标题与标签、打开对应上传页面，并在资源管理器中选中视频；最后上传和发布确认由用户完成。

界面会根据固定胖猫音色的历史语速显示预计配音时长。该数字只用于提醒；生成后程序会重新读取最终 WAV 的真实时长，并以此决定裁剪或提示循环。

首次生成需要加载本地 GPT-SoVITS 模型，通常需要约 30 秒。程序关闭时会停止由本程序启动的模型服务并释放显存。

## 当前固定配置

- 参考音频：`音频.wav`
- 参考文本：`参考文本.txt`
- TTS：GPT-SoVITS v2Pro，CUDA FP16
- 视频输出：H.264、AAC、yuv420p
- 字幕：已知文案与最终 WAV 做中文 CTC 强制对齐，生成 ASS 后烧录
- 字幕参数：可在 `config.json` 独立调整字数、停顿阈值、最短/最长显示时间
- 输出目录：`output/`
- 视频模板目录：`assets/videos/`（自动读取前 5 个支持的视频文件）
- 半自动发布：抖音、小红书网页版（不保存账号密码，不自动点击最终发布）

当前配音、字幕对齐和视频合成链路保持稳定，本版本仅增加模板选择与时长提示。
